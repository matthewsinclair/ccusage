## Decision

hv, 2026-11-06, relayed to vc by devbin-vc (reviewed at 08:23Z by devbin-vc's `date -u`): devbin's dev/opt/brew approach is the canonical one for a Homebrew'd Rust/macOS CLI. Pipeliner is adopting it, and every project uses it, with every difference removed. The contract is `docs/dev-opt-brew.md` in devbin's repository, T1 to T10 (last changed in devbin 0.1.18).

Open, and hv's call: the name of the verb account selection moves to, since hv runs `ccusage use <account>` today.

## Symptom

As of 3968f00, with devbin 0.1.20 vendored. vc re-read every line cited below on 2026-11-06 at 042457d, which changes only vc's board.

- **The verb collides.** `ccusage use <name>` selects the active account profile (`src/cli.rs:262-274`). devbin's contract reserves that verb for the tree switch, `<tool> use [dev|opt|brew]` (T5; devbin's `lib/cmd/use`). `docs/releasing.md:27` already tells the maintainer to ignore devbin's release note `ccusage use brew` for this reason.
- **No publish, no switch and no tree identity.** There is no `ccusage install` opt publish (T2), and the version line is `ccusage <version>` (`src/cli.rs:104-105`), not T4's `ccusage <version> (<tree>, <sha12>[+dirty])`.
- **The formula differs by platform.** On macOS it lays the release binary out as `libexec/ccusage` with devbin's `@@INSTALL@@` (`packaging/homebrew/ccusage.rb:33-36` and `:47`). On Linux it runs `cargo install *std_cargo_args` (`:38`), so a Linux brew install has no libexec tree and no manifest (T1, T3 and T8). The binary's place in libexec (`libexec/ccusage`) also differs from Cldr's `libexec/bin/cldr`.

## How to see it

By the code above. `ccusage use brew` would try to select an account named brew, and `ccusage --version` prints only the version.

## Severity

Medium. A consistency and maintenance defect, with no data or security risk. The `use` collision is a user-facing trap.

## Fix outline

- Adopt the one implementation hv chooses for every tool. devbin-vc recommends that devbin's core carry it for a project's own binaries, and has proposed a devbin issue to hv.
- Account selection moves to another verb, named by hv (see Decision).
- The Linux formula installs the same libexec tree, with its manifest, as macOS does.
