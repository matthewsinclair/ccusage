## Changes, in line with ISSUE:0002 and ISSUE:0003

1. Fold in `4b116b9`: one dropdown entry per account and organisation.
2. Follow the account Claude Code is using. At each refresh, read `oauthAccount.accountUuid` and `organizationUuid` from `.claude.json` in the config the app already resolves, and select the entry with that identity. In ccusage's shared mode `ccusage use` writes exactly that record, so the menu bar follows `ccusage use` with no ccusage-specific code. A manual pick holds until Claude Code's account changes.

4. Read with `-a <user>` as well as `-s <service>`, as Claude Code does, so an item another tool created under the same service name is never read.
5. Stay read-only, and say so in README and in the PR.
