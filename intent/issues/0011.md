## Symptom

`ccusage herdr install` writes the mod, then says nothing until `herdr-app check` returns. On hv's install of 2026-11-13 the check took about two minutes, so install looked hung.

## Cause

`check` in `src/herdr.rs` runs `herdr-app check` with `Command::output()`, which waits with no bound, and install prints its report only after the check returns. Herdr runs the check as a background GUI job: on 2026-11-13 the job waited on the window server under a load average of about 230. A check that never returns would hang install for good.

## Fix outline

1. Before the check, install says on stderr what it waits for, and that Herdr can take a minute or two. stdout keeps install's report, as now.
2. One named constant bounds the wait: five minutes, well past the two minutes hv saw, so it stops only a check that hangs. Past the bound, install kills its herdr-app child, reports the mod as not checked with the command to check it by hand (`herdr-app check DIR`), and exits 0, as it does when herdr-app is not on PATH. Killing the child can leave Herdr's own job running, so install says only that it stopped waiting. A check that fails is still a failure, with exit 1.
3. The bounded wait is a small function on std alone: it spawns the child with piped stdout and stderr, reads each pipe on a thread of its own, and polls `try_wait` until the deadline. No new crate.

RECIPE.md's Watch out, README's Herdr section and a CHANGELOG line under the next release say what install prints while it waits, and what the bound does.

## Acceptance

1. While `herdr-app check` runs, `ccusage herdr install` says on stderr that it is waiting for it, and stdout carries install's report alone.
2. A check still running after the bound is stopped: install reports the mod as not checked, with the command to check it by hand, and exits 0.
3. A check that fails is still reported as failed, in Herdr's words, and install exits 1.
4. A unit test runs the bounded wait against `sleep`, with a bound of a fraction of a second, and the wait ends long before the sleep would, so the suite never waits for the full bound.
