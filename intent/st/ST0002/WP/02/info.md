# WP-02: The which rule: earliest reset first, with the cap from config

## Objective

One pure function takes the accounts' reports, the time now, the cap and an optional model name, and returns the chosen account, the ranked rest and a reason for each. It is the only implementation of the rule: the `which` verb, the TUI marker and `predict`'s simulation all call it.

- **Builder:** cc (proposed). **Depends on:** WP01.
- **Usable:** a report with no error (a failed refresh, a rate limit or a withheld identity), fetched within the cache's TTL, whose `weekly_all` reset is still ahead. A reset that has passed means the cached percent belongs to the previous window. A report that is not usable is unknown: it is listed with its reason and never chosen.
- **Eligible:** a usable account whose `weekly_all` is below the cap. With a model, that model's `weekly_scoped` window must be below the cap too. An account with no scoped window for the model is bounded by `weekly_all` alone.
- **Rank:** `weekly_all` reset ascending, compared to the minute so the endpoint's sub-second jitter cannot decide; then most headroom; then name, so the order is stable. A `weekly_all` with no reset ranks after every dated one, and its reason says so.
- **Nothing eligible:** the result says so and names the soonest reset among the known accounts.
- **Cap:** a new optional key in `config.toml` (proposed: a `[which]` table with `cap = 95`). Its default is defined once, and a value outside (0, 100] is refused. Tests take the cap from the config they write or from that default, never from a literal. Because `Config` denies unknown fields, every older binary refuses a config carrying the key, and README says so.
- **Tests:** the worked example as a fixture test with now at 2026-11-13T05:27Z and the caches' own reset times, jitter included. It must choose hello and rank engineering04, then engineering01 and engineering02, then engineering00. Also each cause of unknown, the headroom tie-break, a missing reset, nothing eligible, and the model filter.
- **Done when:** the rule is one pure function, and AC-02.1 to AC-02.4 are green.
