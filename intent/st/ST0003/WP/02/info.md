# WP-02: The login move: claudeAiOauth between stores, locked, journaled, never lossy

## Objective

One function moves an account's login between two of Claude Code's stores without ever leaving an account with no login or with two live ones. It moves the `claudeAiOauth` value only, under Claude Code's own locks, reads each write back, journals its progress, and finishes an interrupted move on the next run.

- **Builder:** cc. **Depends on:** WP01 passing.
- **Pure plan, impure execution (PFIC):** a pure function turns the three documents and the request into the ordered writes or a refusal. The executor only takes locks, writes, reads back and journals.
- **Stores:** the existing `Stored` reader and writer, for Keychain items and for `.credentials.json` files alike. No second reader of either (Highlander). A Keychain item is never created or deleted, and a store that does not exist is a refusal that says how to make it.
- **Order:** park the outgoing login in its profile, seat the incoming one in the shared store, then remove it from its profile. Each write is read back before the next. The only values overwritten are a profile's empty place and a shared login that has just been parked. A move may have no incoming login, which parks the active one and leaves the shared store without one, or no outgoing one, which seats a login in a shared store that holds none.
- **Locks:** ccusage's own switch lock first, then Claude Code's refresh locks and write lock for the shared store, then for each profile's store in name order. They are held for the whole move, so a session's refresh waits and then adopts what it finds.
- **Refusals, each before any write:** the incoming profile holds no login; the shared store holds a login that is its account's only one and is not the outgoing profile's; the outgoing login does not verify against its profile's email; a resulting document would not fit one `security -i` line.
- **Journal:** a 0600 file in the state directory naming the two profiles and the step reached, and never a token. A run that finds one finishes that move before it does anything else.
- **Tests:** an interruption after each step, on file stores; a held Claude Code lock makes the move wait; each refusal leaves all three documents byte for byte as they were; and on macOS CI, on a disposable keychain as `renewal_write_keeps_claude_items_readable_by_security` uses, a move creates no item and keeps `apple-tool:` on each one it writes.
- **Done when:** AC-02.1 to AC-02.4 are green.
